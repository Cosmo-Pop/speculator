# Speculator
[![Static Badge](https://img.shields.io/badge/arXiv-1911.11778-b31b1b?logo=arxiv&logoColor=red)](https://arxiv.org/abs/1911.11778)
[![DOI](https://img.shields.io/badge/DOI-10.3847%2F1538--4365%2Fab917f-%23fab70c?logo=doi&logoColor=%23fab70c)](https://doi.org/10.3847/1538-4365/ab917f)

This repository contains the code for neural network emulation of stellar population synsthesis (SPS) models for galaxy spectra, originally published in Alsing et. al ([2020](https://ui.adsabs.harvard.edu/abs/2020ApJS..249....5A/abstract)). If you use this code, kindly cite that paper. This fork at [Cosmo-Pop/speculator](https://github.com/Cosmo-Pop/speculator) will be the home for ongoing development of the `torch` version of Speculator, as used in our pop-cosmos generative modelling framework at [Cosmo-Pop/pop-cosmos](https://github.com/Cosmo-Pop/pop-cosmos).

# Installation

You can install the code with pip: 
```bash
pip install git+https://github.com/Cosmo-Pop/speculator.git@torch
```
